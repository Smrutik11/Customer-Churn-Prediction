# Dataset

This project uses the Telco Customer Churn dataset containing 7,043 customer records.

The dataset contains customer demographic information, service details, contract information, billing information, and churn status.

The raw dataset is not included in this repository.

## Dataset File

Place the following file inside this directory before running the notebook:

`WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Dataset Details

- Records: 7,043
- Original Features: 20
- Target Variable: Churn
- Target Classes: Yes / No
